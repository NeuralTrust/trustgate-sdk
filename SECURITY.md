# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately
through GitHub instead:
[**Report a vulnerability**](https://github.com/NeuralTrust/trustgate-sdk/security/advisories/new).

Include what you found, the version of the SDK and the language, and the
smallest steps that reproduce it. If the problem is in the TrustGate gateway
rather than in this SDK, report it here all the same and we will route it.

We will acknowledge the report, keep you informed while we work on a fix, and
credit you in the advisory unless you ask us not to.

## Supported versions

Fixes land on the latest release of each package. Upgrade to it before
reporting, in case the issue is already fixed.

| Package | Registry |
|---|---|
| `@neuraltrust/trustgate` | npm |
| `trustgate-sdk` | PyPI |
